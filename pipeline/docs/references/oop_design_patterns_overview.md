# OOP Design Patterns Overview

Design patterns are reusable solutions to commonly occurring problems within a given context in software design. They are not finished designs that can be transformed directly into code. They are formalizations of best practices that the programmer can use to solve common problems when designing an application or system.

## Design Pattern Categories

| Type | What it does? | Example Pattern |
| :--- | :--- | :--- |
| **Creational** | Deal with how objects are created | Singleton, Factory |
| **Structural** | Deal with how class and object are arranged | Adapter, Decorator |
| **Behavioral** | Deal with how object communicate and behave | Observer, Strategy |
