# Creational Design Patterns

These patterns help abstract the instantiation process, making a system independent of how its objects are created.

## 1. Abstract Factory
Provides an interface for creating families of related or dependent objects without specifying their concrete classes.

## 2. Builder
Separates the construction of a complex object from its representation, allowing the same construction process to create different representations.

## 3. Prototype
Creates new objects by copying an existing object (the prototype) rather than creating them from scratch.

## 4. Factory Method
Provides an interface for creating objects, but lets subclasses decide which class to instantiate.

## 5. Singleton
Ensures a class has only one instance.
